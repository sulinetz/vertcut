# ViralCut 1.2.0

Локальная нарезка длинных видео в вертикальные клипы для YouTube Shorts, TikTok и Instagram Reels. Всё считается на вашем компьютере: видео, звук и текст никуда не отправляются.

## Скачать

| Платформа | Файл |
|---|---|
| **Windows 10/11 x64** | [ViralCut-1.2.0-windows-x64.zip](https://github.com/vanwild11/viralcut/releases/download/v1.2.0/ViralCut-1.2.0-windows-x64.zip) |
| **macOS 11+ Apple Silicon** | [ViralCut-1.2.0-macOS-arm64.zip](https://github.com/vanwild11/viralcut/releases/download/v1.2.0/ViralCut-1.2.0-macOS-arm64.zip) |


**ViralCut-1.2.0-macOS-arm64.zip** — Apple Silicon (M1/M2/M3/M4), macOS 11+.

**ViralCut-1.2.0-windows-x64.zip** — Windows 10/11 x64, нативный `ViralCut.exe`.

Внутри уже есть всё необходимое: модель Whisper Small, ffmpeg, 24 шрифта и определитель
лиц. На macOS дополнительно лежит Node и PO-провайдер для YouTube. На Windows сборка
работает без Node — YouTube может ограничивать качество, но Twitch/Kick, локальные
файлы и прямой эфир работают полностью.

Размер архива ~620 МБ (macOS) и ~600 МБ (Windows), приложение ~868 МБ.

  объём, число клипов и этап обновляются каждые 1,3 секунды.
- Статус «Запись · N мин» появляется сразу после подключения, до загрузки стартовых
  сегментов.

  окно обрезалось до 30 секунд из 120 — теперь собирается через локальный HLS-плейлист,
  без потери длины и без сдвига субтитров.

## Что исправлено в 1.1.1

- **Прямой эфир снова даёт клипы.** Окно не могло извлечь звук: для MPEG-TS-потоков
  (Twitch/Kick) подставлялся несуществующий `init.mp4`, ffmpeg падал, окно повторялось

- «Канал не в эфире» и обрывы связи различаются: понятный статус, проверка раз в 30 секунд,

- Этапы распознавания и рендера больше не затираются строкой «Запись · N мин»; в карточке
  эфира видны объём записи, число клипов и ошибки.
- Реклама отбрасывается на уровне клипа, а не всего 5-минутного окна.

- Несколько эфиров больше не блокируют друг друга (раньше пул был на 3 места).

## Установка


1. Распакуйте архив.
2. Перетащите `ViralCut.app` в «Программы».
3. Запустите. Если macOS скажет «не удалось проверить разработчика» — правый клик по приложению → «Открыть» или:
   ```bash
   xattr -dr com.apple.quarantine /Applications/ViralCut.app
   ```
4. Вставьте ссылку, выберите качество, настройте субтитры и запустите нарезку.

Проекты, клипы и шрифты хранятся в `~/Library/Application Support/ViralCut`. Скачанные MP4 — в `~/Downloads/ViralCut`.

## Что умеет

- YouTube до 1080p, Twitch VOD и клипы, TikTok, Instagram, VK, X, прямые ссылки и файлы.
- Локальное распознавание речи Whisper Small с таймингами слов.
- Длинные ролики (4 часа и больше) идут частями по 15 минут — без зависаний и переполнения памяти.
- Поиск моментов по хуку, плотности речи, паузам, громкости, эмоциям и цифрам.
- Умный кроп 9:16 по лицу, размытый фон или центр.
- Субтитры ASS: подсветка слова, 24 шрифта с кириллицей, 21 цвет, 13 шаблонов, свои TTF/OTF.
- Экономный режим: анализ по аудио, скачивание только выбранных фрагментов.
- До 50 нарезок, редактор клипа, ZIP-экспорт и скачивание в Finder.
- Без API-ключей, аккаунтов, облака и LLM-агентов.

## Требования

- Apple Silicon (arm64), macOS 11 или новее.
- ~1,5 ГБ свободного места после установки.
- Интернет для скачивания исходного видео; для локальных файлов не нужен.

## Ограничения

- YouTube иногда меняет защиту: обновление yt-dlp/PO-провайдера может потребоваться в новых версиях.
- На Intel не запускается.
- Подпись ad-hoc, без нотаризации Apple — отсюда шаг с «Открыть».
- Прямые эфиры Twitch не поддерживаются, только записи и клипы.

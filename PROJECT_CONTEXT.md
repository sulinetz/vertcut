# VertCut — контекст для анализа кода

Это локальное Windows-приложение: превращает длинное видео в вертикальные клипы
9:16 с субтитрами. Работает полностью офлайн: скачивает видео по ссылке (yt-dlp)
или берёт локальный файл, распознаёт речь (faster-whisper), ищет моменты,
кадрирует по лицам, рисует ASS-субтитры и рендерит через ffmpeg.

## Стек

- Python 3.11+ (проверено на 3.13), FastAPI + uvicorn
- faster-whisper (CTranslate2), CUDA при наличии
- OpenCV (YuNet) для лиц, onnxruntime для VAD
- ffmpeg (через imageio-ffmpeg)
- yt-dlp для загрузки
- Интерфейс: чистый HTML/CSS/JS без сборщика, pywebview для окна

## Структура

```
vertcut/            бэкенд
  main.py           FastAPI, все HTTP-роуты
  pipeline.py       оркестрация: скачивание → транскрипт → анализ → рендер
  jobs.py           пулы потоков, сериализация задач по проекту
  db.py             SQLite (WAL), схема и миграции
  config.py         пути, переменные окружения, поиск ffmpeg
  downloader.py     yt-dlp: форматы, cookies, экономичный режим, субтитры
  transcribe.py     faster-whisper: устройство, чанки, повторная проверка
  analyze.py        эвристики «вирусности» + дедупликация
  reframe.py        детекция лиц, врезки (facecam), траектория кропа
  subtitles.py      генерация ASS/SRT, шрифты, переносы, караоке
  render.py         ffmpeg-фильтры: кроп/блюр/полосы, стиль, звук
  platforms.py      безопасные зоны Shorts/TikTok/Reels
  custom_fonts.py   загрузка шрифтов, синхронизация для libass
  live.py           запись HLS-эфиров
  updater.py        проверка обновлений (отключена в этой сборке)
web/                интерфейс: index.html, app.js, styles.css, brand.png
desktop/main.py     окно pywebview, выбор порта, лог
tests/              pytest
tools/              служебные скрипты (enable_cuda.py, version.py)
```

## Как работает обработка

1. `POST /api/projects/draft` создаёт проект без исходника.
2. Загрузка файла или ссылки → `prepare` (скачивание/проба) → статус `review`.
3. `POST /api/projects/{id}/start` → `process_project`:
   - распознавание речи (или готовые субтитры: вшитая дорожка / файл);
   - поиск моментов (`select=smart`) или равная нарезка (`select=even`);
   - рендер клипов в пуле потоков (`_render_one`).
4. Клип можно править и перерендерить (`/api/clips/{id}/rerender`).

## Что уже реализовано

- GPU-транскрипция с откатом на CPU, автоопределение
- экономичный режим для длинных видео (только аудио, потом куски)
- четыре аспекта, умный кроп по лицам, размытый фон, полосы с лицом (band)
- безопасные зоны площадок, караоке-субтитры, 24 шрифта, загрузка своих
- импорт готовых субтитров (.srt/.ass/.vtt) и вшитых текстовых дорожек
- стиль: цветовые пресеты, виньетка, зерно, зум, битрейт, фоновая музыка
- уникализация: зеркало, наклон 0-3°, скорость 1.00-1.10, питч 0.95-1.05,
  склейки пауз, зум на склейках
- split-screen: верх — видео, низ — зацикленный фон из `assets/adhd_bg`
- `timeline.py` пересчитывает слова и траекторию кропа при склейках/скорости
- сохранение fps источника, экспорт ASS/SRT без вжигания
- дедупликация повторов, пресеты длительности до 3 минут
- живой предпросмотр кадра в редакторе клипа

## Известные ограничения

- Склейки режут только паузы по таймингам слов; смена сцен не анализируется.
- Нет диаризации.
- Нет перевода субтитров.
- Загрузка на площадки не реализована.
- `live.py` (HLS) почти не покрыт тестами.
- Тестами покрыты: анализ, субтитры, платформы, раскладки, опции.

## Что хотелось бы от анализа

Ищем: узкие места производительности, баги в конкурентности (потоки, БД,
отмена), ошибки в ffmpeg-фильтрах, уязвимости локального HTTP-сервера,
слабые места тестов.

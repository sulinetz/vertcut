# VertCut — контекст проекта

Локальное Windows-приложение: длинное видео → вертикальные клипы 9:16 с
субтитрами. Всё офлайн: yt-dlp качает источник, faster-whisper распознаёт речь,
эвристики выбирают моменты, OpenCV ведёт кроп по лицам, ffmpeg рисует ASS и
рендерит mp4. Интерфейс — локальный FastAPI + HTML/JS в окне pywebview.

**Этот файл читать первым в каждой новой сессии.** Правила работы — в `AGENTS.md`.

## Как запускать

```powershell
# приложение целиком (окно)
cd vertcut
.\.venv-win\Scripts\python.exe desktop\main.py

# только сервер, UI в браузере
.\.venv-win\Scripts\python.exe -m vertcut --port 8765
```

Данные (база, проекты, модели, логи): `%APPDATA%\VertCut`.
Тяжёлые проекты можно вынести на другой диск: `VERTCUT_PROJECTS` или строка пути
в `%APPDATA%\VertCut\projects_dir.txt`. База и модели остаются на системном диске.
Код и окружение: `vertcut\`.

## Стек

- Python 3.11+ (проверено на 3.13), FastAPI + uvicorn, pywebview
- faster-whisper (CTranslate2), CUDA → CPU fallback
- OpenCV YuNet для лиц, onnxruntime для VAD
- ffmpeg из `imageio-ffmpeg`, yt-dlp для загрузки
- интерфейс без сборщика: `web/index.html`, `app.js`, `styles.css`

### Поток обработки

1. `POST /api/projects/draft` — проект без исходника.
2. Загрузка файла или ссылки → `prepare` (скачивание/проба) → `review`.
   В `meta.audio_tracks` сохраняется список вшитых аудиодорожек и флаг default.
3. `POST /api/projects/{id}/start` → `process_project`:
   - готовые субтитры (вшитая дорожка / файл) или Whisper;
   - `select=smart` — поиск моментов, `select=even` — равная нарезка без речи;
   - рендер клипов в пуле потоков через `_render_one`.
4. Правка и перерендер: `POST /api/clips/{id}/rerender`.
5. Экспорт: `GET /api/projects/{id}/zip`, `GET /api/clips/{id}/subtitles.ass|srt`.

### Рендер одного клипа (`pipeline._render_one` → `render.render_clip`)

Порядок графа ffmpeg (`composition.LAYER_ORDER` — источник истины):

1. **Таймлайн** (`timeline.plan`): если включены склейки — вырезаются паузы
   >0.5 с; слова и траектория кропа пересчитываются. Скорость делит все
   тайминги на `speed`.
2. **Композиция**: кроп по лицам / размытый фон / полоса с facecam /
   split-screen (`vstack`).
3. **Скорость**: `setpts=PTS/speed`.
4. **Зум на склейках**: `split` → `trim` по выходным границам → чётные куски
   +6% → `concat`.
5. **Вставки рекламы** (`replace`): основной ролик делится на куски, между ними
   вставляется видео рекламы; длительность клипа растёт, звук источника стоит
   на паузе, музыка играет дальше.
6. **Стиль**: `hflip`, наклон с запасом 1.12 и обрезкой, зум, цвет, виньетка,
   зерно.
7. **Наложения рекламы** (`overlay`): поверх кадра, анимации fade/slide/scale.
8. **ASS** (субтитры и хук; на время вставок реплики обрезаются) и
   `format=yuv420p`.
9. **Звук**: trim/concat, питч (`asetrate` от реальной частоты источника +
   `aresample` + `atempo`), `loudnorm`, фейды, музыка через `amix`, звук
   нижнего ролика split-screen, звук рекламы на её окне.

Все входы (источник, фон, музыка) нумеруются динамически: 0 — источник,
далее фон split-screen, далее музыка.

### Настройки проекта

`pipeline.DEFAULT_OPTIONS` + `normalize_options` — точка валидации проекта.
Границы, перечисления, да/нет и подписи живут в `composition.SPEC`; оттуда же
их берут редактор клипа (`_clean_clip_edit`), `/api/composition/schema` и UI.
Подробности — `docs/COMPOSITION.md`.

Ключевые группы:

- нарезка: `count` (0 — авто по длине), `min_dur`, `max_dur`, `target_dur`,
  `select`, `picker` (`local` / `auto` / `deepseek` / `gemini`),
  `mood_filter`, `type_filter`, `min_score`
- кадр: `aspect`, `mode`, `layout`, `split_ratio`, `zoom`
- субтитры: `subtitles`, `accent`, `sub_*`, `line_gap`, `export_subs`,
  `subtitle_source`, `subtitle_track`
- стиль: `look`, `vignette`, `grain`, `bitrate`, `music_volume`
- уникализация: `hflip`, `tilt`, `speed`, `pitch`, `jump_cuts`, `cut_zoom`
- split-screen: `bg_video`, `adhd_bg`, `adhd_*_fill`, `adhd_*_scale`,
  `adhd_*_offset_*`, `adhd_bottom_speed`, `adhd_bottom_start`,
  `adhd_bottom_volume`
- реклама: `ads_enabled`, `ad_events` (время — абсолютное время источника)
- источник: `max_height`, `cookies_browser`, `keep_fps`, `language`,
  `audio_track`, `audio_lang` (язык дорожки при скачивании)
- распознавание: `asr_profile` (`fast` / `balance` / `max`), `whisper_model`
- дубляж: `external_audio`, `external_audio_track`, `audio_offset`
- экспорт: `export_order` (`chrono` — по времени источника, `score` — топ моменты)

Настройки клипа хранятся в `clip.settings`; `rerender_clip` копирует из
payload только известные ключи (`CLIP_SETTING_KEYS`). Новую настройку нужно
добавить в `DEFAULT_OPTIONS`, `CLIP_SETTING_KEYS`, `composition.SPEC`, оба
словаря `clip_settings` и `rerender_clip` (см. `AGENTS.md`).

## Split-screen (ADHD)

- Папка фонов: `assets/adhd_bg/` (mp4, webm, mov, mkv, m4v).
  У проекта может быть своё нижнее видео (`local:имя`), загрузка до 300 МБ.
- API: `GET/POST/DELETE /api/adhd-bg`, `GET/POST/DELETE /api/projects/{id}/adhd-bg`.
- Верх — видео, низ — зацикленный фон со случайного места. Звук фона
  по умолчанию выключен, включается `adhd_bottom_volume` (0–50 %).
- `split_ratio` — доля верхней части: UI 0.40–0.85, старые проекты 0.25–0.85.
  Общая геометрия — `render.split_geometry`, её зеркало для превью —
  `web/geometry.js`.
- Заполнение верх/низ: `cover` (с обрезкой) или `contain` (целиком, с полями).
  При `contain` умный кроп верхней части отключается — это осознанный
  компромисс.
- Масштаб (`adhd_top_scale`, `adhd_bottom_scale`), сдвиги по X/Y, скорость
  нижнего ролика и стартовое время — отдельные настройки; нейтральные
  значения дают ту же команду ffmpeg, что и раньше.
- Субтитры по умолчанию ставятся на стык (`middle`); явный выбор пользователя
  не переопределяется.
- Если фонов нет — тёмная подложка, клип всё равно рендерится.
- Документация: `docs/ADHD.md`.

## Реклама

- Библиотека общая для всех проектов: `%APPDATA%\VertCut\ads` (или
  `data/ads` при локальном запуске), `index.json` + файлы.
- API: `GET/POST /api/ads`, `POST /api/ads/text`, `PATCH/DELETE /api/ads/{id}`,
  `GET /api/ads/{id}/file`.
- События клипа: `ad_events` — `{id, asset, kind, start, duration, x, y, w, h,
  opacity, anim_in, anim_out, anim_dur, z, volume}`.
  `kind = "overlay"` — плашка поверх кадра; `kind = "replace"` — вставка:
  основной ролик встаёт на паузу и продолжается с того же места, клип
  удлиняется, звук источника молчит, музыка играет.
- `start` хранится в абсолютном времени источника. Финальная шкала и
  перетаскивание — через `/api/clips/{id}/ad-timeline` и `/api/clips/{id}/ad-map`.
- `ads_enabled` — быстрый выключатель, сами события сохраняются.
- Документация: `docs/ADS.md`.

## Распознавание речи

- Профили `asr_profile`: `fast` (small), `balance` (large-v3-turbo),
  `max` (large-v3). Пустое значение — прежнее поведение.
- Кэш транскрипта учитывает модель, профиль, подсказку, язык, дорожку и файл;
  повторный запуск не пересчитывает речь.
- Словарь терминов (`asr_terms`) попадает в подсказку модели (первые 50 слов).
- Проверка результата: подозрительные тайминги и текст попадают в
  `meta.asr_warning`, повторный проход — по профилю.
- Документация и замер: `docs/WHISPER.md`, `docs/WHISPER_BENCHMARK.md`.

## Статус функций

Реализовано и проверено:

- GPU-транскрипция с откатом на CPU; экономичный режим для длинных видео
- выбор вшитой аудиодорожки для Whisper и звука клипов
- умный кроп по лицам, размытый фон, полосы с лицом, split-screen
- безопасные зоны площадок, караоке-субтитры, свои шрифты
- готовые субтитры: файлы и вшитые дорожки
- стиль: цвет, виньетка, зерно, зум, битрейт, фоновая музыка
- уникализация: зеркало, наклон, скорость, питч, склейки пауз, зум на склейках;
  пресеты «Зеркало», «Зеркало + наклон 0.5°», «Лёгкий/Сильный динамичный»
- датчики CPU/GPU/ENC, температуры GPU и свободного места
- телеметрия энкодера: `h264_nvenc` или `libx264`, лог отката
- пересчёт таймингов и кропа при склейках/скорости (`timeline.py`)
- сохранение fps источника, экспорт ASS/SRT без вжигания
- дедупликация, пресеты длительности до 3 минут, 61–90 с
- выбор моментов нейросетью: DeepSeek или Gemini по тексту транскрипта,
  метка настроения и объяснение у клипа, фильтр настроений и порог оценки,
  кэш ответов, автоматический откат на эвристики; ключи — в «Настройки → Нейросеть»
- живой предпросмотр кадра в редакторе (зеркало, наклон, стык split-screen)
- мастер настройки по шагам: источник (дорожки, дубляж, соседние файлы) → кадр
  (случайный кадр, окно кропа, карточки формата/зон/кадра) → субтитры → количество;
  старый экран доступен переключателем в «Настройки → Интерфейс»
- экономный режим проверен на реальном видео; включается вручную
- СДВГ-композиция: доля кадра, нижнее видео проекта, заполнение, масштаб,
  сдвиги, скорость и звук нижнего ролика; живое превью и перетаскивание стыка
- реклама: библиотека (png, видео, текстовые плашки), наложения с анимациями
  и вставки с паузой основного ролика; таймлайн, перетаскивание, звук
- субтитры: свои файлы в UTF-8/UTF-16/CP1251, привязка к проектам по ссылке,
  скрытие реплик на время вставки рекламы
- длина клипа: «авто» по выбранной длительности, а не жёсткие 10 кусков
- профили Whisper, кэш транскрипта, словарь терминов, предупреждения о качестве
- композиция слоёв и единая схема настроек `/api/composition/schema`

Ограничения:

- склейки работают только при наличии таймингов слов; в режиме «просто
  порезать» без транскрипции они молча не применяются;
- смена сцен не анализируется — режутся только паузы;
- нет диаризации, перевода субтитров, автозагрузки на площадки;
- нейросеть работает только для обычных проектов; прямой эфир (`live.py`)
  по-прежнему режет эвристиками;
- `live.py` покрыт тестами слабо;
- длительность события рекламы в редакторе пока не тянется мышью (только
  перетаскивание по времени);
- удалённый ассет оставляет в старых клипах «висячий» id — такой рендер
  пропускает (не падает);
- бенчмарк Whisper снят на одном видео с авторскими русскими субтитрами;
  профили остаются предварительными до набора 5 фрагментов.

## Диагностика звука (историческая заметка)

При отладке питча использовались два временных скрипта в
`%TEMP%\opencode\`: `audio_wav.py` (рендер аудио в WAV и подсчёт длительности
по размеру файла) и `audio_seg.py` (проверка длительности `atrim` по
отдельному куску). Они **не входят в репозиторий** и были удалены после
диагностики. Вывод, который они дали и который важно помнить:

- длительность audio-контейнера в m4a нельзя мерить по `Duration`, если в
  файле осталась видеодорожка;
- `asetrate` нужно считать от реальной частоты источника (44.1 или 48 кГц),
  иначе клип уезжает и `-shortest` обрезает видео;
- `utils.probe` теперь возвращает `sample_rate`.

Если снова понадобится такая проверка — воспроизводить эти скрипты во
временной папке, а не добавлять в проект.

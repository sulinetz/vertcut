# Композиция клипа

Клип собирается из слоёв. Порядок и границы настроек описаны в одном месте —
`vertcut/composition.py`. Там же их берут проект (`pipeline.normalize_options`),
редактор клипа (`main._clean_clip_edit`) и интерфейс.

## Порядок слоёв

Снизу вверх:

| Слой | Что это | z | Когда активен |
|---|---|---|---|
| `main` | основное видео: кроп, фон, кадр | 0 | всегда |
| `adhd_bottom` | нижний ролик split-screen | 1 | `layout = "adhd"` |
| `ads` | наложения и вставки рекламы | 10 | `ads_enabled` и есть события |
| `music` | фоновая музыка | — (звук) | `music_volume > 0` |
| `subtitles` | караоке-субтитры | 20 | `subtitles` |
| `graphics` | хук сверху | 30 | `subtitles` и `show_hook` |
| `dub` | внешняя звуковая дорожка | — (звук) | `external_audio` |

Порядок — не пожелание, а фактическая последовательность ffmpeg-графа:

1. базовый кадр (кроп/фон/стрим/сплит);
2. скорость и зум на склейках;
3. вставки рекламы (`replace`) — основной ролик встаёт на паузу;
4. стиль (зеркало, наклон, зум, цвет, виньетка, зерно);
5. наложения рекламы (`overlay`) поверх стиля;
6. ASS: субтитры и хук (хук выше субтитров);
7. звук: источник или дубляж, музыка, звук нижнего ролика, звук рекламы.

Хук всегда оказывается выше субтитров, потому что оба рисуются одним проходом
`ass`, а в ASS слой хука = 1, субтитров = 0.

## Единицы измерения

| Величина | Единица |
|---|---|
| `music_volume`, `adhd_bottom_volume` | проценты 0–50 (в рендер уходят как 0.0–0.5) |
| `adhd_top_scale`, `adhd_bottom_scale` | множитель 0.5–2.0 |
| `adhd_top_offset_*`, `adhd_bottom_offset_*` | доля ширины/высоты, −0.5…0.5 |
| `adhd_bottom_speed` | множитель 0.25–4.0 |
| `split_ratio` | доля верхней части: UI 0.40–0.85, проект 0.25–0.85 |
| `speed`, `pitch` | множитель: 1.0–1.1 и 0.95–1.05 |
| `sub_size`, `sub_offset`, `line_gap` | пиксели кадра 1080×1920 |
| `zoom` | проценты 100–120 |

Интерфейс получает эти границы с сервера и выставляет `min`/`max`/`step`
ползункам сам (атрибут `data-schema`, множитель `data-schema-scale` для
процентов). Подсказка на русском приходит в `title`.

## API

- `GET /api/composition/schema` — слои и все настройки:
  `key`, `type`, `layer`, `label`, `hint`, `default`, `min`, `max`, `step`,
  `unit`, `choices`.
- `GET /api/clips/{id}/composition` — какие слои активны у конкретного клипа
  и сколько у него наложений/вставок.

Схема проверяется тестом: каждый ключ из `pipeline.CLIP_SETTING_KEYS` обязан
там быть, значения по умолчанию совпадают с `DEFAULT_OPTIONS`, у каждой
настройки есть подпись и подсказка.

## Как добавить настройку

1. Добавить поле в `pipeline.DEFAULT_OPTIONS` и в `CLIP_SETTING_KEYS`.
2. Добавить `Setting` в `composition.SPEC`: тип, слой, границы, подпись,
   подсказку.
3. Если ключ есть в `ClipEdit` — он подхватится автоматически: `_clean_clip_edit`
   валидирует через `composition.clamp_strict`.
4. Если настройка нужна эфирам — добавить в `live._settings` (там используется
   `CLIP_SETTING_KEYS`, обычно ничего делать не нужно).
5. В интерфейсе повесить `data-schema="ключ"` на поле — границы и подсказка
   приедут из схемы.
6. Прогнать `pytest` и проверить реальным рендером.

Если тип значения мусорный, проект берёт `default` (старые данные не ломаются),
а API редактора отвечает 400: тихо портить клип нельзя.

## Время и вставки

Время событий рекламы хранится в **абсолютном времени источника**, как и слова
субтитров. В финальную шкалу оно переводится только функциями `timeline.py`:

- `insert_spans` — точки вставок после склеек и скорости;
- `inserted_time` / `unmap_inserted` — прямая и обратная шкала;
- `event_window` — окно наложения в финальной шкале (используют рендер и API);
- `insert_window` — окно самой вставки;
- `rebase_insert_words` — сдвиг слов на длину вставок (субтитры не звучат над
  рекламой; дополнительно `build_ass(..., blackouts=...)` режет реплики).

Одна формула на всех — иначе таймлайн в редакторе разъезжается с файлом.

## Совместимость

- Новые настройки по умолчанию нейтральны: старый проект без ключей рендерится
  как раньше.
- `sub_size = false` (следствие старого бага мастера) читается как 118, а не
  как 70.
- Диапазоны `speed`, `pitch`, `tilt`, `split_ratio` совпадают с теми, что были
  в проекте, поэтому уже сохранённые клипы не меняются.

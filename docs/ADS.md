# Реклама: библиотека и события

## Библиотека

Глобальная, `%APPDATA%\VertCut\ads` (или `DATA_DIR/ads`):

- `index.json` — метаданные под `threading.RLock`, запись атомарная;
- файлы `{id}.png`, `{id}.mp4`, …; проект хранит только id;
- виды: `image` (PNG/JPG/WEBP/GIF, включая прозрачность и анимацию GIF),
  `video` (MP4/WEBM/MOV/MKV), `text` — текст и промокоды, отрендеренные Pillow в PNG;
- лимиты: изображение 25 МБ, видео 300 МБ; битый файл даёт 400, а не 500.

Роуты:

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/api/ads` | список ассетов |
| POST | `/api/ads` | загрузка файла (multipart `file`) |
| POST | `/api/ads/text` | текст → PNG (`text`, `color`, `background`, `font_size`) |
| PATCH | `/api/ads/{id}` | переименование |
| DELETE | `/api/ads/{id}` | удаление файла и записи |
| GET | `/api/ads/{id}/file` | файл для превью |

## События клипа

Клип хранит `ad_events` (до 40) и `ads_enabled`:

```json
{"id": "e1", "asset": "a1b2c3", "kind": "overlay|replace",
 "start": 104.2, "duration": 2.0,
 "x": 0.66, "y": 0.05, "w": 0.28, "h": 0.2, "opacity": 1.0,
 "anim_in": "none|fade|slide|scale", "anim_out": "...",
 "anim_dur": 0.3, "z": 0, "volume": 1.0}
```

- `start` — **абсолютное время исходного видео** (как слова). В интерфейсе
  показывается итоговое время; пересчёт — `timeline.insert_spans`,
  `inserted_time`, `unmap_inserted`, `unmap_time`.
- `overlay` — картинка/видео/текст поверх кадра с `enable='between(t,…)'`.
- `replace` — основное видео **встаёт на паузу**, играет реклама, потом видео
  продолжается с того же места. Клип становится длиннее на сумму вставок;
  звук основного видео тоже на паузе, звук рекламы — с `volume`.
- Фоновая музыка не прерывается: вставка делается в основную дорожку до
  микса музыки.
- В СДВГ-режиме реклама закрывает весь кадр 9:16, нижнее видео в этот момент
  не видно.
- Субтитры сдвигаются, на время вставки их нет. Наложение, начавшееся до
  вставки и кончающееся после, продолжается поверх рекламы.
- Событие внутри вырезанной паузы прилипает к ближайшему сохранённому моменту.

Если `ad_events` пуст или `ads_enabled=false`, команда ffmpeg **побайтно
совпадает** с прежней (`tests/test_ads_render.py`).

## Интерфейс

В редакторе клипа: библиотека с превью, загрузка файла, текст плашки,
кнопки «Наложение» и «Вставка» (на текущем моменте плеера), полоса событий и
список. Блок на полосе можно перетащить: позиция переводится в исходное
время через `/api/clips/{cid}/ad-map`. Роут
`/api/clips/{cid}/ad-timeline` отдаёт итоговые времена и вставки; параметр
`events` позволяет посчитать раскладку до сохранения клипа.

## Рекламный футаж / Баннер (в редакторе клипа)

В модальном окне редактора клипа доступен отдельный блок «Рекламный футаж / Баннер»
(настраивается только на уровне клипа, не в мастере проекта):

- `promo_footage`: ассет из библиотеки `/api/ads` (включая `.gif` и видео) или
  `random` (детерминированный выбор видео/GIF по id клипа, без статичных PNG).
- `promo_mode`:
  - `overlay` — наложение поверх видео с шириной `promo_scale` (30–100 %),
    позицией `promo_pos` (`bottom` над безопасной зоной площадки, `top`,
    `center` или `custom` по `promo_x`/`promo_y`), и расписанием
    `promo_timing` (`loop`, `start`, `periodic`, `end`);
  - `split_bottom` — нижняя плашка под основным видео (`vstack`), доля
    основного видео `promo_split_ratio` (0.40–0.85), заполнение `promo_fill`
    (`cover`/`contain`). Если в клипе был включён СДВГ-фон, футаж занимает
    нижнюю область вместо него без двойного стека.
- `promo_key_color` (а также `key_color` у `ad_events`): хромакей `green`
  (`0x00FF00:0.25:0.1`) или `black` (`0x000000:0.15:0.1`).
- `promo_audio_vol`: громкость звука футажа (0–100 %, по умолчанию 0 %),
  подмешивается через `amix` с выравниванием по окнам показа (`adelay`).

# СДВГ-режим (split-screen)

Основное видео сверху, зацикленный фон снизу. Режим включается
`layout="adhd"`; старые клипы без новых ключей рендерятся как раньше.

## Геометрия

`render.split_geometry(width, height, ratio)` — чистая функция, зеркало
`web/geometry.js` (`VCGeometry.splitGeometry`). Тест сравнивает обе реализации.

- `ratio` — доля верхней области: интерфейс 40–85%, бэкенд 25–85%,
  чтобы старые `split_ratio` 0.3–0.4 не менялись;
- высота верхней части округляется до чётной, как в `vstack`;
- границу можно тянуть мышью в превью мастера и редактора клипа.

## Настройки

| Ключ | По умолчанию | Диапазон | Смысл |
|---|---|---|---|
| `split_ratio` | 0.5 | 0.25–0.85 | доля верхней области |
| `adhd_bg` | `""` | имя файла / `local:…` | нижний ролик, пусто — `bg_video` |
| `adhd_top_fill` | `cover` | cover/contain | заполнить или вписать целиком |
| `adhd_bottom_fill` | `cover` | cover/contain | то же для низа |
| `adhd_top_scale` | 1.0 | 0.5–2.0 | масштаб внутри верхней области |
| `adhd_bottom_scale` | 1.0 | 0.5–2.0 | масштаб нижнего ролика |
| `adhd_top_offset_x/y` | 0 | −0.5–0.5 | смещение верхней картинки |
| `adhd_bottom_offset_x/y` | 0 | −0.5–0.5 | смещение нижней картинки |
| `adhd_bottom_speed` | 1.0 | 0.25–4.0 | скорость зацикленного низа |
| `adhd_bottom_start` | −1 | −1–7200 | старт низа; −1 = случайный |
| `adhd_bottom_volume` | 0 | 0–50 | звук низа, %; 0 = выключен |

При нейтральных значениях строка `-filter_complex` совпадает с прежней —
это проверяет `tests/test_adhd_render.py`. `cover` не меняет кадрирование
верхней части, `contain` показывает кадр целиком с чёрными полями.

## Нижнее видео

- общая библиотека: `assets/adhd_bg/`, `GET /api/adhd-bg` отдаёт имя,
  размер, длительность и разрешение (с кэшем по mtime);
- превью библиотечного файла: `GET /api/adhd-bg/file/{name}`;
- своё видео проекта: `POST /api/projects/{pid}/adhd-bg` (до 300 МБ),
  лежит как `adhd_bottom.*`, в настройках `adhd_bg="local:adhd_bottom.mp4"`;
- удалить своё видео: `DELETE /api/projects/{pid}/adhd-bg`.

Нижний ролик зациклен (`-stream_loop -1`), звук по умолчанию не подключён.
Если звук включён, он смешивается с основным после `loudnorm`; при скорости
низа ≠ 1 к нему применяется `atempo`.

## Превью

Высота областей в превью и экспорте считается одной формулой. В редакторе
клипа граница рисуется в canvas и тянется мышью; в мастере — на превью кадра.
Содержимое нижнего ролика в редакторе показывается тёмной областью, в мастере —
кадром выбранного файла.
